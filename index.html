Overview

Sparse autoencoders identify features inside language models, but translating those features into faithful natural-language explanations remains difficult. SAEExplainer learns to describe a feature vector directly and then uses the target model’s own activations to check whether the description captures what triggers that feature.

The explainer is first trained on existing feature explanations. It then generates candidate explanations and texts based on them. The target feature’s activation on those texts supplies a preference signal: stronger, feature-specific candidates are favored over plausible descriptions that fail to activate the feature. Two rounds of Direct Preference Optimization refine the explainer with this feedback.
