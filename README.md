# SAEExplainer — EMNLP 2026 project page

Website: https://mndu.github.io/saeexplainer/

A static research page for **SAEExplainer: Interpreting SAE Features with Activation-Guided Preference Optimization**. The restrained layout follows the Language Ranker project page and the DynamicD reference: centered title and author block, bracketed links, and separate white panels for Overview, Results, and BibTeX.

The original algorithm framework appears before Overview. Results contain two comparisons from the supplied paper: the generative-accuracy columns of Table 1 and a qualitative case from Table 2. All displayed values and author details were checked against `1066_SAEExplainer_Interpreting.pdf`. The SAEExplainer explanation in the qualitative case is explicitly abridged.

Open `index.html` locally to preview; no build tools are required. The `[Paper]` link opens the supplied PDF, and `[Code]` opens the research repository at https://github.com/he-jingyi/SAEExplainer.
